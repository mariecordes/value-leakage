# Superseded design

An earlier version of the causal intervention, retired before any continuation was
sampled. Kept because it is the record of why the cut moved, not because it produced
any reported result.

That design cut the reasoning immediately before the model's first explicit total
calculation. Resampling from those cuts showed the boundary was too late: all twelve
natural resamples at one trace reproduced the same total, because the prefix had
already fixed both the population and the spots per giraffe. At that boundary the
model is only being asked to perform a multiplication it has already set up.

The current design cuts before whichever quantity the model settles first, which is
what leaves the answer open. See `../README.md`.

`raw/` responses from this stage remain under `../raw/`, and are the evidence for the
twelve-of-twelve result above.
